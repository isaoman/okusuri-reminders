# おくすりスタンプ通知ジョブ

このリポジトリは、公開Webアプリの服薬通知を毎分確認するRender Cron Job専用です。利用者の薬や服薬記録、ChatGPTの認証情報は保存しません。

- `notify.py` がサイトの `/api/cron` を呼び出します。
- `render.yaml` が毎分実行するStarterプランのジョブを定義します。Renderの最低料金は月額1米ドルです。
- `REMINDER_KEY` はRenderの環境変数に秘密として設定します。ソースに書き込まないでください。
- ご友人は公開サイトを開いて自分の名前と通知を登録します。ChatGPT・Render・GitHubへのログインは不要です。

通知は端末の通信、ブラウザの許可設定、プッシュサービスの稼働状況に左右されます。実機でテスト通知と指定時刻の通知を確認してください。
